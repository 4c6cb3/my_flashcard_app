# 暗記アプリ　memoly

memory(覚える)とlight(軽い)が名前の由来な、AIが作った暗記アプリ。
https://4c6cb3.github.io/my_flashcard_app/

## ざっくりした使い方
① オプションより、学習モードを選択する

② .csvファイルを取り込む、または自分で新規デッキを作ることで、「学習を開始」をタップする

③ 画面タップで答えを表示し、自分で暗記できていたかを評価する（必要に応じて検索ボタンをタップ）

④ これを繰り返してめちゃくちゃmemolyしてね
